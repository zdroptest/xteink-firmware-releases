# MonochromeOS releases

Firmware updates and downloadable extras for MonochromeOS, a firmware for the
Xteink X4 Pro based on [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader).

- Firmware images are attached to this repo's releases and installed by the
  device's built-in updater.
- `dictionaries/` holds the dictionary pack the device offers under
  Settings → Reading → Dictionaries. `dictionaries.json` lists each pack's
  files with sizes and CRC32 checksums.

## Dictionaries

- **WordNet (English)**: built from Princeton WordNet 3.1 in StarDict format.
  See `dictionaries/wordnet-LICENSE.txt` for its licence.
